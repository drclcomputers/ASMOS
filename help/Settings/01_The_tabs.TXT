# The tabs

- Display: the screen size and its colours, 16 or 256 (only what this
  machine and its video card can take; the tooltip says why not; both
  take effect at the next start), the desktop pattern and colours, the
  screen saver, the speed options, and Characters (the code page for
  accents and symbols).
- Sound: sound on or off, the start-up chime, the Sound Blaster's volume.
- Clock: the date, the time and the time zone.
- Network: the address from DHCP (it shows what it got, and Renew asks
  again), or untick it and type the IP address, gateway, netmask and DNS
  server in. They apply at once.
- Printers: the printer's kind and port.
- Devices: what is plugged in: keyboard, mouse, joystick, ports, sound
  and network cards. Double-click one to set it up (the joystick opens
  its own window). Refresh looks for a joystick again.
- System: start in the desktop or the text shell, FileF's windows, and
  a few options for troubleshooting.

Save keeps the settings in ASMOS.CFG. Some need a restart: Save says so.
