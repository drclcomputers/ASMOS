# The shell

ASMTerm is the command line in a window. Type a command and press Enter.
Type help for the list of commands, help and a topic for more.

- Up and Down bring back earlier commands.
- PgUp and PgDn scroll.
- File > Paste types the clipboard's text.

A few commands: ls, cd, cat, cp, mv, rm, mkdir, write, format, play,
ping, ftp. A name with spaces goes in quotes. The topics of help: files,
time, info, network, devices, programs, shell.
